# Blind, Deaf, and Mute — Legal Pages

Public legal-page website for the **Blind, Deaf, and Mute** Minecraft Bedrock add-on and companion Discord bot.

## Pages
- [Home](docs/index.html)
- [Terms of Service](docs/terms.html)
- [Privacy Policy](docs/privacy.html)

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose **main** and **/docs**, then click **Save**.
4. After deployment, use:
   - Terms: https://daylightishere.github.io/Blind-Death-and-Mute/terms.html
   - Privacy: https://daylightishere.github.io/Blind-Death-and-Mute/privacy.html

**Before submitting to Discord:** Review the policies against the actual bot code, particularly which data are stored, how long logs remain, and the deletion procedure. These are working drafts, not legal advice. The repository title currently spells "Death" rather than "Deaf"; links must match the repository's actual spelling.

Do **not** commit your Discord bot token, `.env` file, session codes, or database.
